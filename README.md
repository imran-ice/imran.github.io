# Academic Portfolio Website

A responsive, static academic portfolio built with HTML, CSS, and vanilla JavaScript. It is ready to publish with GitHub Pages.

## Files
- `index.html` — page content and structure
- `style.css` — responsive styling
- `script.js` — mobile navigation and current year
- `assets/` — place your CV and optional profile image here

## Before publishing
1. Replace `Your Name`, `YN`, role, department, university, biography, and email.
2. Update Google Scholar, LinkedIn, GitHub, and project links.
3. Add your CV as `assets/cv.pdf` (or change the link in `index.html`).
4. Add actual publications and update project descriptions/status.
5. Replace the initials placeholder with a profile photo if desired.

## Publish with GitHub Pages
1. Create a GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Visit `https://YOUR-USERNAME.github.io` after deployment finishes.

No build tools or framework installation are required.
